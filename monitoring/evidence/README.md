# Подтверждение работы мониторинга

Успешный запуск: [GitHub Actions 43006598088](https://github.com/abbos-trnv/mlops_realtime_fraud_detector_airflow_hw/actions/runs/43006598088).
Проверенный коммит: `c109d50199f36fd0198cbe2b9d18e9ff6fd96eb5`, 11 ноября 2026.

На чистом Ubuntu runner были собраны и запущены реальные Kafka, PostgreSQL,
CPU CatBoost, Prometheus, Node Exporter, Grafana и Airflow. Только входной CSV
синтетический: 6000 размеченных строк с января по апрель 2019. Модель обучается
и делает inference, сообщения действительно проходят Kafka и пишутся в БД.

- [live-check.json](live-check.json): три targets UP, число записей растёт,
  запросы всех 25 панелей возвращают данные, три алерта созданы provisioning.
- [model-reload.json](model-reload.json): реальный DAG опубликовал версию
  `20261111T105141`, скорер подхватил её с сохранением id контейнера,
  PostgreSQL содержит новые скоры этой версии, метрика аннотации присутствует.
- [flow-alert.json](flow-alert.json): после pause симулятора правило остановки
  потока перешло в `firing`; симулятор восстановлен через finally/unpause.

Три регрессионных теста также прошли. Полные compose.log и retrain.log доступны
в артефакте monitoring-live-evidence этого запуска. Эти большие логи не включены
в Git. Команды повторения описаны в [инструкции](../README.md).

Ограничение локальной проверки: на Windows-ноутбуке с 8 ГБ RAM Docker Engine
повторно начал возвращать HTTP 500. Три Prometheus target успели стать UP,
но визуальную проверку Grafana на этом ноутбуке завершить не удалось.
Скриншоты не подменяются макетами; приведённые подтверждения относятся к CI.

После перезагрузки 11 ноября локальная проверка `check_monitoring.py` тоже
прошла на Windows и пользовательском CSV: все три targets UP, все 25 панелей
содержат данные, число записей выросло с 1865 до 1951, три алерта созданы.
Перед этим остановлены 18 автоматически запускавшихся контейнеров CVAT.
Запрос диска учитывает как Linux `/`, так и диск данных Docker Desktop
`/parent-distro/mnt/docker-desktop-disk`. Визуальная проверка через встроенный
браузер по-прежнему не выполнена: браузерный инструмент завершился по таймауту.
